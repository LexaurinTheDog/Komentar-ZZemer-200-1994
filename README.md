# Komentář k zákonu č. 200/1994 Sb., o zeměměřictví a o změně a doplnění některých zákonů souvisejících s jeho zavedením

Otevřený komentář k zákonu o zeměměřictví — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; zeměměřické činnosti ve veřejném zájmu, digitální technické mapy, ověřování výsledků, autorizovaný zeměměřický inženýr, Česká komora zeměměřičů a přestupky.

Konsolidované znění: dokument e-Sbírky `SB-1994-00200_2026-01-01`.
